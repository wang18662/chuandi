传递 (Chuandi) Demo 录制说明 —— 方法一：实时录制（OBS）
================================================================

适用：想快速拿到一段可发的实机演示，或手动操作展示 Boss 战。


---------- 第一步：启动游戏（干净画面）----------
双击本目录下的  record_standalone.bat
  -> 会以「独立游戏模式」启动，1920x1080 窗口，没有编辑器 UI。
  -> 进错地图的话，用记事本打开 bat，在最后一行末尾加：
       -map=/Game/Chuandi/Maps/你的关卡
  -> 想全屏就把 -windowed 改成 -fullscreen（但 OBS 得改用「游戏捕获」）。


---------- 第二步：配置 OBS ----------
1) 加源
   - 来源面板点「+」-> 选「窗口捕获」（最稳）。
   - 窗口下拉里找带 Chuandi 字样的那个（独立模式标题一般是项目名 Chuandi）。
   - 「捕获光标」取消勾选。
   - 若列表里没有，先把 bat 跑起来、游戏窗口出现后再回来加源。

2) 视频
   - 设置 -> 视频 -> 基础画布 1920x1080，输出分辨率 1920x1080，FPS 60。

3) 输出（画质 + 文件大小）
   - 设置 -> 输出 -> 输出模式「高级」。
   - 录制格式：mp4。
   - 编码器：有 N 卡选「硬件(NVENC)」，否则 x264。
   - 速率控制：NVENC 选 CQP，值 18~20（越小越清晰、文件越大）；
               x264 选 CRF，值 18。
   - 关键帧间隔：2。预设：quality / high quality。

4) 音频
   - 桌面音频默认（游戏音效会被录进去）；不想带麦就把「麦克风」静音。

5) 录制
   - 点「开始录制」-> 切到游戏窗口打 Boss -> 打完点「停止录制」。
   - 产物默认在 OBS 设置里写的「视频」路径，是一段 mp4，可直接发。


---------- 常见坑 ----------
- 窗口捕获黑屏：把 bat 里 -windowed 改成 -fullscreen，源改用「游戏捕获」；
  或退而用「显示器捕获」（会录到桌面其他东西，注意隐私）。
- 画面被拉伸：确认 OBS 画布/输出都是 1920x1080，且游戏窗口没被拖小。


---------- 备选：不想用 bat ----------
也可以直接在编辑器里按 Play（PIE）再用 OBS 窗口捕获，
区别只是 PIE 画面带编辑器视口边框。bat 模式画面最干净。


---------- 方法二（备用，电影级离线渲染）----------
见同目录 capture_movie.py：用 Movie Render Queue 离线渲染图片序列，
适合做作品集/评审片。需先启用 Movie Render Pipeline 插件并建好
Level Sequence（如 /Game/Chuandi/Cinematics/DemoMaster）。
